# Kode × Barista Hustle Recipe Trainer

An interactive FB45 brewing trainer with Simple and Advanced modes.

## Run

Open `index.html` in a modern browser, or serve this folder with a static web server. An internet connection loads the hosted Barista Hustle fonts.

The downloadable bundle is `kode-recipe-trainer-v2.zip`.

## Features

- Five strength choices, from 13 g to 15 g coffee with 250 g water.
- Bloom, turbulence and drawdown animation.
- Advanced controls for dose, water, temperature, flow, bloom, pours and timing.
- Circular or centre pouring, adjustable circle diameter and time per circle.
- Responsive phone and laptop layouts.

The brewing animation is an illustrative teaching model, not a calibrated prediction of extraction or TDS. Font assets remain hosted and are not bundled.
